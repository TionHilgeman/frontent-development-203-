## Toegankelijkheidstest 1/2 (week 1)

<details>
  <summary>uitwerken na test in 2<sup>e</sup> werkgroep</summary>

  ### Bevindingen
  Lijst met je bevindingen die in de test naar voren kwamen:
  1. de html code is niet goed gevalideerd.
     Ik heb de code in een validator gedaan en er kwamen meer den 1001 errors uit. dit kan komen door dat er elementen niet werken of gewoon omdat de code van de website slecht is geschreven.
  3. worden geen li of ul tags gebruikt.
     de tags li en ul zijn belangrijk voor de toegankelijkheid om de volgorde van de screen reader te bepalen. als deze er niet in zitten kan de screenreader vast lopen.
  5. Alle media dingen zijn niet goed.
     de videos die op de achtergrond staan van de pagina zijn niet te pauzeren. Dit moet anders, omdat de video kan afleiden van het doel van de pagina.
  7. dark light niet suported.
     Min laptop staat standaard altijd op dark mode, maar als ik hem op lightmode zet veradnerd er niets in de pagina. er is dus maar 1 variant gemaakt.
  9. de animaties zijn niet goed uitgewerkt in de site.
      er zitten weinig goed uitgewerkte animaties in de site. het enige dat goed werkt is het in en uit zoomen van de afbeeldingen bij een hover.

</details>
